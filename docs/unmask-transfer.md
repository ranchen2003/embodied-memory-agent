# 遮挡换位任务的迁移诊断

先前的目标定位实验使用颜色相同的紫色圆环。这里固定检查 RoboMME-Plus 公开训练分段中 VideoUnmaskSwap 的全部三条轨迹，编号为 15、16、17，分别对应简单、中等和困难。智能体依据示范中的方块颜色选出应抓起的容器。容器覆盖方块后持续换位，中等和困难回合还设置了挡板。使用固定数据版本 `ea22d395232719c13df778a2c2219a1ebdfe367e`。

## 对照条件

预测只读取公开指令和第 0 至 756 帧的前视观测，每两帧采样一次。基于连续的颜色可见证据和颜色消失后的位置关系，将可见方块与候选容器建立初始对应。根据容器外观替换了紫色圆环检测器，检测阈值在首次打分前确定。四种对照共用这份候选检测与对应关系。

| 对照 | 根据历史对应找当前目标的方法 |
|---|---|
| 静态近邻 | 选择当前画面中最靠近原位置的候选容器。 |
| 单轨运动 | 用先前圆环实验中的速度估计和门限，逐帧保留一个关联候选。 |
| 多路径运动 | 使用同一关联规则，最多保留四个路径候选。 |
| 固定槽位 | 若开始关联和执行时的候选槽位双向重合比例至少为 80%，复用圆环的运动片段和置换传播。 |

全部预测完成后，才读取独立的公开训练评分文件。按首次执行帧的标注计算二维像素误差，沿用圆环实验的 5 像素命中阈值。额外统计当前检测点中最接近参考位置的误差，区分候选检测不足与关联失败。这个最优误差只用于诊断。

## 初次运行结果

四种方法均命中 0/3。

| 轨迹 | 现象 | 当前检测点的最小误差 |
|---|---|---:|
| 15 简单 | 第 36 帧看到红块，第 40 帧形成初始容器候选。首尾槽位双向重合为 0%，固定槽位对照未给出预测。静态和多路径给出了同一个错误位置。 | 25.99 px |
| 16 中等 | 蓝块在前视中有 18 个采样帧符合检测条件，当前检测集合中存在命中位置。程序未能在颜色消失时建立方块到容器的初始对应。 | 4.37 px |
| 17 困难 | 当前前视颜色检测器始终未得到可用的红块证据，未形成初始对应。 | 46.49 px |

将腕部视频作为单独的证据诊断，三个文件均与同版本发布清单中的 SHA-256 一致。第 17 条同一截点前，前视符合红色阈值的最大连通域仅 3 像素，腕部第 2 帧已经能清楚看见红块，最大红色连通域有 475 像素。腕部有 18 个采样帧的红色区域超过现行前视检测器的 260 像素上限。该诊断未改变任何前视预测或评分。数据给出了两个具体改动方向，一是尺度适配与双视角绑定，二是管理持续运动的对象身份。

## 复跑入口

从项目根目录运行。数据路径可指向独立实验目录，数据清单、视频和评分标签均使用同一固定版本。

```powershell
python scripts/evaluate_unmask_transfer.py `
  --coverage <数据清单路径> `
  --video-dir <前视视频所在目录> `
  --wrist-dir <腕部视频所在目录> `
  --references <独立评分标签路径> `
  --output <输出 JSON 路径>
```

`--wrist-dir` 可省略。输出包含评估截点、可见帧、候选位置、关联结果和逐回合评分。结果属于三个公开训练回合的离线首次选择诊断，不含机械臂动作或测试集成功率。
